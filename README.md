**Twin Streets** — a spot-the-difference game about one quiet night street, shown twice. Two near-identical pictures sit side by side: a cat on a wall, a striped shop awning, a moon that will not stay put, a bicycle that comes and goes. Find all seven differences in each of three rounds before the clock runs out.

Every picture is drawn by code — no image files, nothing borrowed. The rounds get harder as the night deepens: subtler differences, less time. Wrong clicks cost points, hints cost more, and a clean round pays a time bonus.

## How to play

- **Click** a difference on either picture to ring it on both.
- **H** — spend a hint (two per round, 50 points each).
- **P** — pause. **M** — mute the sounds. **Space** — start, or move to the next round.
- **Wrong clicks** cost 25 points, so look twice.
- Your best score is kept in the browser between visits.

Run it locally with `node serve.ts`, then open http://localhost:8080. Hand it in with `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` first to choose where the output goes).

## The three rounds

1. **Willow Lane** (90 seconds) — dusk on the street: the cat, the awning, the moon.
2. **Market Lane** (75 seconds) — deeper night: the lamppost, the chimney smoke, the tree.
3. **Rooftop Garden** (60 seconds) — the hardest to spot: the clock, the curtains, the moon's face.
